# Plan: 02-01 DGA Generators & Tranco Corpus Builder

## Goal
Implement `core/dga_generators.py` with deterministic algorithms for the 6 target DGA families (Cryptolocker, Necurs, Qakbot, Conficker, Bamital, Suppobox/Matsnu) and a Tranco benign corpus builder. Generate `data/tranco_benign_sample.csv` (15,000 benign domains) and `data/dga_malicious_sample.csv` (15,000 malicious domains across the 6 families, 2,500 each).

## Requirements Covered
- DGA-01: Cryptolocker DGA implementation
- DGA-02: Necurs DGA implementation
- DGA-03: Qakbot DGA implementation
- DGA-04: Conficker DGA implementation
- DGA-05: Bamital DGA implementation
- DGA-06: Suppobox/Matsnu DGA implementation
- CORP-01: Tranco benign corpus synthesizer/loader (15,000 domains)
- CORP-02: Malicious corpus generator (15,000 domains)
- CORP-03: Datasets output to `data/`

## Tasks
1. Implement `core/__init__.py`.
2. Implement `core/dga_generators.py`:
   - Family-specific generator functions: `generate_cryptolocker`, `generate_necurs`, `generate_qakbot`, `generate_conficker`, `generate_bamital`, `generate_suppobox`.
   - Unified dispatcher `generate_dga_domains(family, count, seed)`.
   - Benign corpus generator `build_tranco_benign_corpus(count, seed, csv_path)`.
   - Corpus builder CLI/function `build_datasets(benign_count=15000, malicious_count=15000)`.
3. Generate `data/tranco_benign_sample.csv` and `data/dga_malicious_sample.csv`.
4. Validate generated CSVs (check row counts, non-empty values, correct schema, class distribution).

## Verification
- Both CSVs exist with exactly 15,000 rows each.
- Malicious dataset contains 2,500 domains for each of the 6 families.
- Domains are valid domain strings with proper TLDs.
