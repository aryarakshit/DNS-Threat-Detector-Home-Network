# Plan: 06-01 Threat Hunter, Master CLI Runner & SOC Dossier Report Generator

## Goal
Implement `core/threat_hunter.py` and `run_dns_detector.py` to process the 7-day home DNS telemetry (140,000 queries), score unique domains with the trained Random Forest model, correlate host NXDOMAIN burst behavior, triage flagged anomalous domains (differentiating true DGA beacons and DNS tunneling from benign CDN/DKIM false positives), and auto-generate `reports/dns_threat_study_report.md` with complete investigation dossiers and the populated resume bullet.

## Requirements Covered
- HUNT-01: Pre-filter cache (skipping `.arpa`, `.local`, Tranco Top-10k)
- HUNT-02: Telemetry correlation per domain (query volume, NXDOMAIN counts, device IPs, beacon periodicity)
- HUNT-03: Automated SOC triage verdict classification
- REP-01: Automated report generator creating `reports/dns_threat_study_report.md`
- RUN-01: Master CLI script `run_dns_detector.py`

## Tasks
1. Implement `core/threat_hunter.py`:
   - Domain aggregator collecting per-domain telemetry from the event stream.
   - Fast-path filtering for `.arpa`, `.local`, and Top-10k Tranco whitelist.
   - Model inference integration via `predict_domain()` / batch inference.
   - Behavioral triage correlation engine:
     - Flag if P(DGA) >= 0.65 or Shannon Entropy >= 3.65.
     - Classify into:
       - Confirmed Malicious DGA Beacon (High P(DGA) + High NXDOMAIN ratio > 50% from infected LAN host)
       - Confirmed DNS Tunneling / Hex C2 (High subdomain entropy + TXT/NULL queries)
       - Investigated Benign Anomaly (High entropy CDN/DKIM cleared via NOERROR / CNAME / known ASN)
     - Build structured SOC dossiers.
2. Implement report generator function in `core/threat_hunter.py` or helper writing `reports/dns_threat_study_report.md`.
3. Implement `run_dns_detector.py`:
   - Master end-to-end runner CLI with `argparse` and `rich` tables/formatting.
   - Supports `--train`, `--evaluate`, `--hunt`, `--report`, `--all`.
4. Execute `python run_dns_detector.py --all` and verify report generation.
