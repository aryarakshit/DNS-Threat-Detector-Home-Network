# Plan: 04-01 ML Classifier Training & Evaluation Pipeline

## Goal
Implement `core/model_trainer.py` to train a scikit-learn Random Forest model on the 30,000 labeled domain corpus using an 80/20 stratified split with 5-fold cross-validation on the training split. Ensure the bigram/trigram language models are strictly fitted on the training split (anti-leakage requirement). Achieve Precision >= 95.0% and Recall >= 94.0% on the held-out test set. Serialize the trained pipeline and feature extractor to `models/dga_detector.joblib`.

## Requirements Covered
- ML-01: Scikit-learn RandomForestClassifier with 14 features
- ML-02: 5-Fold Stratified Cross-Validation on training split
- ML-03: Evaluation metrics (Precision >= 95.0%, Recall >= 94.0%, F1, ROC-AUC, Confusion Matrix)
- ML-04: Per-family detection recall breakdown across all 6 DGA families
- ML-05: Serialization to `models/dga_detector.joblib`

## Tasks
1. Implement `core/model_trainer.py`:
   - Dataset loader joining benign (`tranco_benign_sample.csv`) and malicious (`dga_malicious_sample.csv`) sets.
   - Stratified train/test splitting (80% train, 20% test).
   - Anti-leakage feature extraction: fit `DomainFeatureExtractor.fit_language_model()` on benign training samples only, then extract 14 features on train and test sets.
   - 5-fold cross-validation on training fold.
   - Train `RandomForestClassifier(n_estimators=200, max_depth=18, random_state=42)`.
   - Comprehensive test evaluation: Precision, Recall, F1, ROC-AUC, Confusion Matrix, Feature Importances, Per-Family Recall.
   - Serialization of artifact bundle to `models/dga_detector.joblib`.
2. Run training and verify performance benchmarks:
   - Check Precision >= 95.0%
   - Check Recall >= 94.0%
   - Check all 6 DGA families are individually detected with high recall.
3. Save training summary JSON/metrics for later reporting.

## Verification
- `models/dga_detector.joblib` is created and can be loaded with `joblib.load()`.
- Test set Precision >= 95.0% and Recall >= 94.0%.
- Per-family recall evaluated for cryptolocker, necurs, qakbot, conficker, bamital, suppobox_matsnu.
