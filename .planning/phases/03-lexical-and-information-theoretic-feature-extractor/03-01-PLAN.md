# Plan: 03-01 Lexical & Information-Theoretic Feature Extractor

## Goal
Implement `core/feature_extractor.py` containing the `DomainFeatureExtractor` class that extracts Second-Level Domains (SLD) offline via `tldextract` (with no internet dependency) and computes all 14 lexical and information-theoretic features specified in Section 5B of the blueprint. Provide strict separation for fitting benign bigram and trigram probability tables with Laplace smoothing to prevent data leakage.

## Requirements Covered
- FEAT-01: Offline SLD extraction via `tldextract`
- FEAT-02: Shannon entropy and normalized metric entropy
- FEAT-03: Character ratios (length, vowel, consonant, digit, hex, unique)
- FEAT-04: Transition and streak features (max consonant streak, max digit streak, switch frequency)
- FEAT-05: Benign bigram and trigram log-likelihood with Laplace smoothing and rare bigram ratio
- FEAT-06: Anti-leakage separation (fit / transform API)

## Tasks
1. Implement `DomainFeatureExtractor` in `core/feature_extractor.py`:
   - Offline `tldextract` configuration.
   - Individual feature calculation methods.
   - `fit_language_model(benign_domains)` for training fold Laplace smoothed n-grams.
   - `extract_features(domain)` -> Dict[str, float].
   - `extract_features_dataframe(domains_list)` -> pd.DataFrame with all 14 columns.
2. Test extraction against benchmark benign and malicious domains.
3. Validate math correctness (entropy of uniform strings vs repeat chars, streak detection, rare bigrams).

## Verification
- Test script extracts 14 features for various test domains (`google.com`, `x9k2m7p4q1v8.ru`, `bamital` hash).
- Assert all 14 features are finite, non-null numerical values.
- Assert Shannon entropy is 0.0 for identical characters (`aaaa.com`) and ~3.5-4.0 for random strings.
