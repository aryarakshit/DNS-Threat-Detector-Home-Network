# Plan: 05-01 Pi-hole & Zeek Log Parsers & 7-Day Simulator

## Goal
Implement `core/log_parsers.py` with multi-format log parsing (Pi-hole dnsmasq text, Pi-hole FTL SQLite database, Zeek TSV, Zeek JSON) and a deterministic 7-day home network DNS traffic simulator producing 140,000 queries in `data/home_dns_7days.jsonl` across the 5 LAN devices. The dataset must simulate everyday benign browsing, benign high-entropy CDN/DKIM anomalies (with NOERROR responses), and active C2/DGA beacons from `192.168.1.55` and `192.168.1.99` (with >85% NXDOMAIN rates).

## Requirements Covered
- LOG-01: Pi-hole log parser (`dnsmasq` text and `pihole-FTL.db` SQLite)
- LOG-02: Zeek DNS log parser (TSV format and JSON format)
- SIM-01: Deterministic 7-day home network simulator (140,000 events in `data/home_dns_7days.jsonl`)
- SIM-02: Inclusion of benign high-entropy CDN/DKIM false-positive candidates
- SIM-03: Active DGA/C2 beacon simulation from `192.168.1.55` and `192.168.1.99` with NXDOMAIN bursts

## Tasks
1. Implement `core/log_parsers.py`:
   - Unified `DNSQueryEvent` dataclass / schema:
     `timestamp`, `client_ip`, `device_name`, `query`, `qtype`, `rcode`, `answers`.
   - `parse_pihole_log(filepath)`: parses standard dnsmasq line format.
   - `parse_pihole_sqlite(db_path)`: parses SQLite queries table.
   - `parse_zeek_dns_log(filepath)`: auto-detects TSV (#fields) or JSON lines.
   - `generate_home_network_logs(output_path, total_queries=140000, days=7, seed=42)`.
2. Generate `data/home_dns_7days.jsonl`.
3. Validate simulated traffic:
   - Check total count = 140,000 queries.
   - Check device distribution across 5 LAN hosts.
   - Verify presence of normal queries, high-entropy benign anomalies, and DGA beacons.
   - Verify NXDOMAIN ratio for `192.168.1.55` and `192.168.1.99` on DGA domains exceeds 85%.

## Verification
- `data/home_dns_7days.jsonl` exists and contains exactly 140,000 valid JSON lines.
- Unit parser functions successfully parse simulated or real Pi-hole and Zeek test snippets.
